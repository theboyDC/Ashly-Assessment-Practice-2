- Access modifiers are java's way of letting you control which classes can access your method. They allow you to keep some information hidden
- They matter because some pieces of code shouldn't be displayed to everyone.
- THe private modifier means that only classes within the specific package can see your code or that field.
- To see what you made private you would have to create a setter and a getter
- The public modifier means there is nothing private about that code and can be seen from anywhere as long as that class is called
- The protected modifier is a hybrid of both so your code can be seen but you encrypted it
- Making everything public is not always a good idea because for example when working with a bank account we don't want every class to have access to the balance or secret pin
